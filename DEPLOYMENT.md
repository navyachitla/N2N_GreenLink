# GreenLink – Complete Production Deployment & Architecture Guide

This document contains the step-by-step instructions for deploying the **GreenLink Sustainable Living Ecosystem** to a clean, production-ready environment while maintaining **100% functionality** for local development.

---

## 🏛️ System Architecture Overview

### 1. Local Development Setup (Default)
```text
React SPA (localhost:5173) ──▶ Spring Boot API (localhost:8080) ──▶ Local PostgreSQL (localhost:5432/greenlink_db)
```
- **Zero Config Required**: Running `mvn spring-boot:run` locally connects directly to your local PostgreSQL database without needing manual environment variables.

### 2. Production Cloud Setup
```text
Vercel Frontend (HTTPS) ──▶ Render Backend Web Service (HTTPS) ──▶ Cloud PostgreSQL Database (Neon.tech / Render)
```
- **Data Persistence Guarantee**: Every user registration, marketplace order, carbon log, and waste submission performed on the Vercel site is stored directly in your Cloud PostgreSQL database.

---

## 🛠️ Step-by-Step Production Deployment Guide

### STEP 1: Create a Free Cloud PostgreSQL Database (Neon.tech)

1. Go to 👉 **[neon.tech](https://neon.tech)** and sign in with your GitHub account (`navyachitla`).
2. Click **Create Project** and name it: **`greenlink-db`**.
3. Once created, copy your **Connection Details**:
   - **Host**: `ep-cool-sample-12345.us-east-2.aws.neon.tech`
   - **Database**: `neondb`
   - **User**: `neondb_owner`
   - **Password**: `<YOUR_NEON_PASSWORD>`
   - **Full JDBC URL**: `jdbc:postgresql://ep-cool-sample-12345.us-east-2.aws.neon.tech/neondb?sslmode=require`

---

### STEP 2: Deploy Spring Boot Backend to Render.com

1. Go to 👉 **[render.com](https://render.com)** and sign in with GitHub (`navyachitla`).
2. Click **New + ➔ Web Service** and select your repository **`navyachitla/N2N_GreenLink`**.
3. Configure Web Service settings:
   - **Name**: `greenlink-backend-api`
   - **Region**: Oregon (US West) or Singapore
   - **Branch**: `main`
   - **Root Directory**: `backend`
   - **Runtime**: `Docker`
   - **Instance Type**: **Free ($0/month)**
4. Scroll down to **Environment Variables** and add the following 5 variables:

   | Environment Variable | Value |
   | :--- | :--- |
   | `SPRING_DATASOURCE_URL` | `jdbc:postgresql://<NEON_HOST>:5432/neondb?sslmode=require` |
   | `SPRING_DATASOURCE_USERNAME` | `<NEON_USER>` |
   | `SPRING_DATASOURCE_PASSWORD` | `<NEON_PASSWORD>` |
   | `SPRING_JPA_HIBERNATE_DDL_AUTO` | `update` |
   | `JWT_SECRET` | `GreenLinkSuperSecretProductionJwtSigningKey2026SecureMinimum256Bits` |

5. Click **Create Web Service**.
6. Render will build the Docker container and start your Spring Boot application. Once the deployment status turns **Live**, copy your backend URL:
   👉 Example: `https://greenlink-backend-api.onrender.com`

---

### STEP 3: Deploy React Frontend to Vercel

1. Go to 👉 **[vercel.com](https://vercel.com)** and sign in with GitHub (`navyachitla`).
2. Click **Add New... ➔ Project** and import **`N2N_GreenLink`**.
3. Configure Project Settings:
   - **Framework Preset**: `Vite`
   - **Root Directory**: Select **`frontend`**
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Expand **Environment Variables** and add:

   | Environment Variable | Value | Note |
   | :--- | :--- | :--- |
   | `VITE_API_BASE_URL` | `https://greenlink-backend-api.onrender.com/api` | ⚠️ **Must include `/api` at the end!** |

5. Click **Deploy**.
6. Vercel will build your React application and issue your live HTTPS URL:
   👉 Example: `https://n2n-greenlink.vercel.app`

## 🧪 Verification & Testing Checklist

Once deployed, test the complete end-to-end flow (**Vercel ➔ Render ➔ Cloud PostgreSQL**):

1. **User Registration**:
   - Open your Vercel URL (`https://n2n-greenlink.vercel.app`).
   - Click **Register Now**, enter a new email (`testuser@greenlink.org`), password, and click **Register**.
   - ✅ **Expected Result**: User account is created and stored permanently in your Cloud PostgreSQL database.

2. **Login & Authentication**:
   - Log out and log in with your newly registered credentials.
   - ✅ **Expected Result**: JWT token is generated by Render backend, saved in `localStorage`, and redirects to `/dashboard`.

3. **Eco Marketplace & Cart Checkout**:
   - Browse eco-products, add items to cart, and complete checkout.
   - ✅ **Expected Result**: Order record is saved in Cloud PostgreSQL, product stock is decremented, and +15 Green Reward Points are credited to the user's account.

4. **Carbon Calculator & Recycling**:
   - Submit a monthly carbon footprint log or waste item.
   - ✅ **Expected Result**: Calculation is performed, stored in Cloud PostgreSQL, and reward points are updated.
